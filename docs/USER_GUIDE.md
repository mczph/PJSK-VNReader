# 使用说明

## 启动与选择剧情

Windows 用户可运行 `SEKAI-NOVEL-0.1.7-x64.exe` 便携版，无需安装 Node.js。首次读取目录、背景、配音与角色模型需要联网；已经完整缓存的章节可以离线复用。

主菜单提供开始阅读、继续故事、读取存档、资源管理、设置和退出程序。主界面播放循环 BGM；组合页播放对应 SEKAI 场景音乐，VIRTUAL SINGER 使用其主线开场音乐。音乐遵循 BGM 音量设置，最小化暂停，离开对应界面停止。

设置中可选择日服、国服、台服、国际服或韩服。剧情文本使用所选服务器原文，没有机器翻译。主线按组合选择；活动显示活动名称；个人剧情包含角色介绍和卡片前篇 / 后篇，可按角色筛选。章节展示 26 名主要角色中的实际出场角色和 Q 版头像，排除 NPC。

## 阅读与演出

- 文字未显示完整时，点击画面或按空格先补全文字，配音继续播放。
- 文字完整后，再次操作中断当前配音并进入下一句；手动推进略过中间演出等待，直接恢复目标对白的角色、动作终态、背景和镜头状态。
- 文字已经完整时，一次操作即可推进。隐藏对白时先恢复对白显示。
- 自动播放保留正常演出节奏，等待文字和语音完成后，再按设置的自动等待时间推进。
- 快进包含未读内容；跳转到末句不会自动把整章标记为已读。

底部控制栏可操作自动、快进、存档、读档、Backlog、跳转、配音重播、隐藏对白与设置；全屏状态下也可以使用。鼠标右键可设置为隐藏对白或打开阅读设置。

## 快捷键

剧情快捷键在阅读界面生效，输入文字时不触发。F 可在主界面和阅读界面切换全屏；F11 是桌面版原生全屏快捷键。

| 按键 | 功能 |
| --- | --- |
| Space / Enter / → | 补全文字；文字完整后推进 |
| ← | 上一句 |
| A | 切换自动播放 |
| K | 切换持续快进 |
| 按住 Ctrl | 临时快进，松开恢复此前状态 |
| S / F5 | 快速存档 |
| Shift+S | 打开存档菜单 |
| L | 打开读档菜单 |
| F9 | 读取快速存档 |
| B / Backspace | 打开 Backlog |
| J | 打开跳转菜单 |
| V | 重播当前对白配音 |
| H | 隐藏 / 显示对白 |
| Esc | 打开阅读设置，或关闭当前阅读菜单 |
| F / F11 | 全屏 |

按钮悬浮提示和设置页可以查看按键说明。输入框获得焦点或输入法正在组合文字时，剧情快捷键不生效；焦点在按钮上时，Space / Enter 使用该按钮的原生操作。

## 存档、已读与 Backlog

提供 48 个普通存档、一个快速存档和自动续读书签，按 4 页浏览；原有 1–8 号存档保留编号和内容。新存档展示场景预览，旧存档可使用章节封面。保存内容包括章节、服务器、对白位置和保存时间；读档直接恢复相应演出状态。Backlog 只记录实际阅读或手动推进的对白，支持搜索、按角色筛选、回到该句与配音重播。

章节已读状态按阅读记录计算，也可手动标记或取消。桌面版在应用数据目录的 `reader-state.json` 保存存档、设置和阅读记录；浏览器版使用当前站点的 localStorage。导入的字体保存在当前应用 / 浏览器的 IndexedDB。

桌面设置提供打开数据目录及导入 / 导出存档备份。字体不包含在 JSON 备份内，换设备后需重新导入。不同浏览器、端口或桌面版之间的存档不会自动同步。

## 批量下载与资源管理

1. 在主菜单打开 **RESOURCE / 资源管理**。
2. 选择服务器与剧情类型，搜索章节并勾选。每批最多 500 章，可选择当前筛选结果。
3. 下载队列依次准备章节，每章内部使用四路并发缓存音画资源，并下载对应模型与特效。
4. 暂停会等待当前章节完成；重启应用后队列保留，需要手动继续。缺失资源可通过重试补齐。

章节缓存页可清理章节的独占资源，保留其他章节仍在使用的共享资源。资源文件页可按类型或关键词筛选，支持全选全部文件、选择筛选结果和取消选择；全选全部文件跨筛选和分页生效。

一键清空缓存会清理所有服务器的资源缓存，并取消待下载项；存档、设置、已读记录和导入字体保留。清理前先暂停队列并等待当前章节完成。被清理的章节下次阅读会重新下载。

## 画面、音量与画质

设置的“播放器画面比例”可选择完整 16:9 显示，或填满屏幕并裁切演出边缘。裁切保持背景与 Live2D 的比例，不拉伸画面；对白和操作栏按实际屏幕布局，保持可操作。活动目录播放所选剧本的场景 BGM，个人剧情使用角色所属组合音乐；设置与资源管理页延续主界面音乐，音量为 BGM 设置的 40%。选中剧情合集时保留目录滚动位置，返回章节页也恢复原选择。

支持浅色 / 暗色 / 跟随系统外观、对白透明度、字体导入、角色主题色、字号、逐字间隔、标点停顿和自动等待时间。BGM、角色语音与场景音效可分别调节。

Live2D 节能档使用 30 FPS、最高 1 倍画布精度；均衡与高画质档使用 60 FPS、最高 1.5 / 2 倍精度，受设备像素比限制。关闭角色或特效可减少负载。最小化 / 隐藏窗口暂停声音、演出与自动阅读。

图片当前采用资源站的 WebP，不经过程序二次压缩或缩放，但不是全部最高画质。2026-10-01 抽查中，背景与封面的 WebP 和 PNG 尺寸一致，存在有损压缩；完整卡面为 2520×1440，另缓存的小封面为 940×530。Live2D 使用模型原始纹理，抽查一歌模型为 2048×2048 PNG。不同素材尺寸可能不同。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 首次打开没有声音 | 先点击画面或按键解除浏览器自动播放限制，检查各音量设置 |
| 目录或资源下载失败 | 检查网络及代理，重新同步目录或重试章节；服务不会自动翻译文本 |
| 个别服务器没有音画资源 | 程序尝试日服相同路径的公共媒体，文本仍保留所选服务器原文 |
| 角色模型缺失或演出不完整 | 查看提示、重试章节；部分特殊指令或新模型尚未完全适配 |
| Live2D 卡顿 | 切换节能档，或关闭角色 / 特效 |
| 缓存占用较大 | 在资源管理中按章节清理，或清空全部缓存 |
| 浏览器端存档丢失 | 确認仍使用同一浏览器与站点地址，清除站点数据会删除本地记录 |

本项目尚未实现区域 / 特殊剧情、姓名输入和剧情分支；粒子、转场等效果是网页重建，不能保证与 Unity 原演出完全一致。
